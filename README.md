# PEKA

Private Enterprise Knowledge Assistant

PEKA is a private enterprise operational intelligence platform designed to integrate organizational knowledge, CMDB data, infrastructure telemetry, monitoring systems, and operational procedures into a conversational AI assistant.

## Current Components

- FastAPI
- Ollama
- Qdrant
- Open WebUI
- RAG-based retrieval
- DokuWiki ingestion pipeline
